# Orbit — лаунчер приложений

Лёгкий русскоязычный каталог приложений с поиском, категориями и сохраняемой в браузере библиотекой.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из этой папки:

```powershell
python -m http.server 4173
```

Затем откройте `http://localhost:4173`. Добавленные приложения и библиотека хранятся в `localStorage` этого браузера. Кнопка «Открыть» ведёт на официальный сайт приложения.

## Вход через Google и Apple

В интерфейсе подготовлены кнопки OAuth. Для включения входа:

1. Создайте OAuth-приложения в Google Cloud Console и Apple Developer.
2. Впишите публичные client ID / Service ID в `config.js` и зарегистрируйте соответствующие HTTPS redirect URI у провайдеров.
3. Реализуйте серверные callback-маршруты `/auth/callback/google` и `/auth/callback/apple`: проверку `state`, обмен authorization code на токены на сервере и создание сессии приложения.

Один статический файл не может безопасно завершить вход: нужны выданные владельцем client ID, серверная проверка callback, а для Apple также серверная настройка JWT client secret. Секреты провайдера нельзя помещать в `config.js`.

## О текущем каталоге

Встроенный каталог демонстрационный. Он открывает официальные веб-версии приложений; установка нативных программ на устройство требует desktop-оболочки и проверенных установочных пакетов/манифестов.
